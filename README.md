## 🎲 PIG Dice Game Highlights

PIG is a turn-based multiplayer dice game where players try to reach the target score before their opponents.

### Features

- Supports 2–4 players
- Random dice rolling
- Turn-based gameplay
- Current turn score tracking
- Total player score tracking
- Players can choose whether to roll again
- Rolling a `1` ends the current turn
- Rolling a `1` resets the current turn score
- Risk-based gameplay
- Automatic winner detection
- 50-point winning target
- Game automatically stops when a player reaches 50 points
- Final score display

### 🎲 How PIG Works

1. Choose the number of players between 2 and 4.
2. The current player chooses whether to roll the dice.
3. If the player rolls `2–6`, the number is added to the current turn score.
4. The player can continue rolling or stop.
5. If the player rolls a `1`, the current turn score becomes `0` and the turn ends.
6. When a player stops voluntarily, their current turn score is added to their total score.
7. The first player to reach `50` points wins the game.
